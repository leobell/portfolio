MERN Stack

E-Learning Platform

A full online course platform, Udemy-style: instructors create courses structured into modules and lessons, students explore the catalog, enroll and track their progress in real time.

React Node.js Express MongoDB Tailwind JWT Cloudinary

For students

  • Course catalog with search, category filters and pagination
  • Independent enrollment management
  • Course player with module/lesson navigation, Cloudinary or YouTube video support
  • Progress tracking, "continue watching", completion badges
  • Star ratings and reviews, one per course, editable
  • Personal dashboard with summary stats

For instructors

  • Create and edit courses organized into modules and lessons
  • Upload cover images and lesson videos to Cloudinary
  • Draft / published status per course
  • Instructor dashboard with course and student stats
  • Safe deletion with cascading cleanup of related data

Security & architecture

  • Authentication via bcrypt-hashed passwords or Google OAuth
  • JWT-based sessions with automatic expiration handling
  • Full password reset flow via email (Nodemailer)
  • Role-based access control (Student, Instructor, Admin) with ownership checks
